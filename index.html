InputApr 2026

One constraint,
eight hours

Hillingdon Council× Brunel University

Hillingdon Council handed the hackathon an open brief and one hard requirement. Personal data belonging to residents could not travel. Not to an API, not to a bucket, not off the desk it was sitting on.

No resident data leaves the machine

The obvious move was a cloud API key and a good demo. Instead I ran every model locally — GLM through Ollama, spaCy for entity recognition, EasyOCR behind it — and shipped a working GDPR-compliant redaction tool with a four-person team inside the eight hours. It won gold. It took sponsor prizes from Microsoft and ICS.AI, and it converted into a work experience offer inside the council’s own digital services team, where I later built the assistant further down this page.

Everything I have built since carries the same shape: a system that does real work, and an explicit written line it will not cross.

01Input

Ingest the page as pixels

A scanned document arrives as an image, not text. GLM running locally through Ollama reads it, with EasyOCR behind it as a fallback — and the weaker fallback geometry is blocked by default, so quality never degrades quietly when the primary model struggles.

  • Tauri
  • FastAPI
  • GLM via Ollama
  • EasyOCR
  • PyMuPDF
02Process

Find what counts as personal

spaCy classifies entities across the recovered text — names, addresses, dates of birth, national insurance numbers, phone numbers. Each detection keeps its coordinates on the page, because the redaction has to land on pixels, not on a text layer.

  • spaCy
  • OpenCV
  • Python
03System

Burn it in, keep the labels

Redactions are burned into the pixels rather than layered as removable overlays, so a released file cannot be peeled back open. Field labels stay readable while their values disappear — a reviewer can still see that an address was held, just not which one.

  • Pillow
  • PyMuPDF
  • SQLite
04Output

Seal it, and stop there

The export carries a signed identifier that resolves only on the server that produced it, never a public registry. And the tool stops: it does not make the final disclosure decision. A human signs that off, every time, on purpose.

  • React
  • Vite
  • Signed local IDs
